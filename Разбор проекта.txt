Схема зависимостей для чтения
GameMain.cpp
  └─ Engine::Run()
       └─ GameWorld
            ├─ GameObject ─ Component (база)
            │                ├─ TransformComponent ─ Matrix2D ─ Vector
            │                ├─ SpriteRenderer ──── RenderSystem ─┐
            │                ├─ Collider ────────── PhysicsSystem │ ResourceSystem
            │                ├─ Rigidbody                        │
            │                ├─ Input → Movement                  │
            │                ├─ Follow (AI)                       │
            │                └─ Stats / Attack / Camera / Audio ──┘
            └─ DeveloperLevel (Scene)
                 ├─ MazeGenerator
                 ├─ Player
                 ├─ AI → Creeper → CreeperSpawner
                 └─ Wall / Floor / Music
Правило: не переходи к следующему файлу, пока не можешь объяснить, кто его создаёт и кто вызывает его методы. Весь путь — примерно 25 файлов ядра, реально читается за 2–4 вечера.
