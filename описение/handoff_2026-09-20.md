## Блокеры / открытые проблемы
1. **Краш 0xC0000005 при запуске exe напрямую** (~10 с в игровом цикле; из VS, по словам
   пользователя, игра работает). Лог обрывается после "Program was started!" (Engine.cpp:28).
   WinDbg уже установлен (winget). Главные подозреваемые (по первому анализу):
   - реентерабельность: `LoadNextLevel()` из `OnTriggerEnter` прямо во время итерации PhysicsSystem
     (`DeveloperLevel.cpp:63` + `PhysicsSystem.cpp:19-27`, Unsubscribe из деструкторов во время цикла);
   - инвертированный аккумулятор `GameWorld::FixedUpdate` (`GameWorld.cpp:27` — `if (fixedCounter > step) return;`);
   - dangling-ключи в `triggersEnteredPair` после Unsubscribe (`PhysicsSystem.cpp:93-105`);
   - утечки `new Trigger/new Collision` (`PhysicsSystem.cpp:42,85,99`).
   План: снять дамп (WinDbgX), затем чинить через отложенную смену уровня (по образцу
   `EnqueueLateAction` + `LateUpdate` из референса Rogalique_Engine-main/GameWorld).
2. Незакрытые баги первого анализа: скорость без deltaTime в Rigidbody, `delete this` из
   конструкторов компонентов (MovementComponent/SpriteColliderComponent/FollowComponent),
   O(n²)-физика, магические числа.
